# 再也不用哭着做文献汇报PPT了

一个用于10分钟中文文献汇报的 Agent Skill：以科学问题串联证据，基于固定15页模板制作可编辑PPT。

## 能做什么

- 按“背景—科学问题—方法—结果—讨论—文献联想—总结”组织论文。
- 使用内置模板，保留版式、母版、装饰线与留白，替换新论文内容和全部旧备注。
- 从原文核验数字、图号、图源和引用，区分作者结论与汇报者推论。
- 默认讲述9分30秒，预留30秒给停顿和切页。
- 交付前检查文字溢出、图表清晰度、来源与可编辑性。

这是供AI助手执行的工作流程与模板，不是无需模型即可运行的独立PPT生成程序。实际制作需要客户端具备论文读取、PPTX编辑和渲染能力。

## 版式与页序

中文用微软雅黑，英文与数字用Times New Roman，文字黑色，画布16:9。默认1.5倍行距，科学问题页与总结页用3倍行距；封面和致谢页不显示页码。

| 页码 | 内容 |
|---|---|
| 1 | 中英文标题、文献信息、汇报人、日期与主题背景图 |
| 2 | 目录 |
| 3—5 | 整体背景、具体问题、研究缺口 |
| 6 | 科学问题Q1—Q3 |
| 7 | 研究对象与方法 |
| 8—11 | 回答科学问题的结果证据 |
| 12 | 局限、研究差异与自己的科学问题 |
| 13 | 一到两篇延伸文献回应自己的问题 |
| 14 | 三句短句总结本文，3倍行距 |
| 15 | Thanks everyone！ |

## 安装

下载本仓库的完整文件，不要只复制SKILL.md，因为模板和使用说明也是技能的一部分。

### Codex本地客户端

将本仓库内容放入客户端支持的技能目录下，文件夹名使用`literature-report-10min`；常见用户技能目录为`~/.agents/skills/`。若客户端提供“安装技能”入口，也可通过该入口安装完整目录。

### Claude Code

将完整目录放入`~/.claude/skills/literature-report-10min/`。具体技能发现方式以客户端当前文档为准。

其他支持Agent Skills的客户端按其技能安装方式载入整个目录。

## 使用

提供主论文PDF或可访问的全文来源，并提出：

> 使用literature-report-10min，根据这篇论文制作10分钟中文文献汇报，基于内置模板输出可编辑PPTX。

也可仅请求逐页提纲或按页讲稿。请注明汇报日期、听众和特殊要求；当次明确要求优先于默认配置。

请在请求中指定汇报人姓名；未指定时使用“汇报人”占位。模板只含版式和占位内容，制作新汇报时应填入经核验的论文信息。

## 证据要求

材料不足时标出缺口：不为凑三个问题硬造分析，不为凑两张图重复或生成研究证据，不把摘要阅读写成全文核验。AI生成内容仍需汇报者核对论文与讲述逻辑。
