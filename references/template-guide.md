# 固定文献汇报模板

## 文件与版式

- 默认源文件：`../assets/11.pptx`。它是15页、16:9的可编辑PPTX模板，已清除个人姓名、旧讲稿、修订记录、批注作者、旧封面图片和文档作者元数据。
- 模板SHA-256：`972249fed8f513065629ac3d395bff8372552f25a29d0c919f4f7353408be3b6`。
- 正文页保留白底、左上标题、蓝灰色细线、底部浅色细线及右下页码。封面和致谢页采用通用布局。
- 封面背景为白色占位，制作汇报时应换成与本次论文相关且可使用的图片，并注明来源。

## 页面映射

| 模板页 | 新汇报用途 | 替换方式 |
|---|---|---|
| 1 | 标题页 | 替换标题、作者/期刊/日期、汇报人及主题背景 |
| 2 | 目录页 | 保留五项目录，按SKILL.md统一字号 |
| 3—5 | 背景页 | 替换占位短句，加入核验过的证据图及图注 |
| 6 | 科学问题页 | 替换Q1—Q3问题文本 |
| 7 | 研究方法页 | 加入原文方法图或准确的可编辑流程图 |
| 8—11 | 结果页 | 按实际证据分配Q1—Q3，加入主论文结果图 |
| 12 | 讨论页 | 概括局限、不同观点并提出自己的问题 |
| 13 | 文献联想页 | 以一到两篇外部文献回应上一页问题 |
| 14 | 总结页 | 用本次论文的三句短句总结，正文3倍行距 |
| 15 | 致谢页 | 使用`Thanks everyone！`，移除可见页码 |

## 实施与检查

1. 在输出目录复制源PPTX，原位替换占位内容，保留主题、母版、版式、装饰线与原生对象；不要用整页图片模拟可编辑模板。
2. 清除`TITLE`、`123`、`Author et al.`、`Publication`、`year`、`Name`和日期占位符；按用户信息填写汇报人，未提供时保留通用占位。
3. 模板备注页为空。制作汇报时按需要写入新的讲稿；不要加入个人信息、机构标识或与本次论文无关的旧内容。
4. 检查封面背景、母版和版式中的图片与文字，确保来源可用，且没有与新论文无关的遗留内容。
5. 逐页渲染最终输出，检查文字溢出、图注、页码和图表清晰度。若导入工具丢失母版、背景或几何关系，修复后再交付。
